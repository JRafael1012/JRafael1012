# Portafolio

## Estructura

- `src/pages/`: páginas y rutas de Astro.
- `src/components/`: componentes visuales reutilizables.
- `src/layouts/`: estructura compartida y metadatos.
- `src/styles/`: estilos CSS.
- `src/data/`: textos y datos de proyectos.
- `src/scripts/`: lógica que se ejecuta en el navegador.
- `public/images/`: imágenes accesibles desde `/images/`.
- `public/videos/`: videos accesibles desde `/videos/`.

Edita `src/data/portfolio.ts` para cambiar el nombre, la descripción, el correo y los proyectos. Los trabajos incluidos son ejemplos conceptuales.

## Comandos

```sh
npm run dev
npm run build
npm run preview
```
